What Each File Does
====================

📱 SCREENS (User-facing pages)
- AuthScreen: Login and sign up forms
- FeedScreen: Shows all memories in timeline
- CreateMemoryScreen: Photo picker + form to post
- LogBooksScreen: Create/join/switch LogBooks
- ProfileScreen: Settings and logout

🧩 COMPONENTS (Reusable UI)
- MemoryCard: Displays single memory with photos

🔧 SERVICES (Business logic)
- pocketbase: All API calls to backend
- imageService: Compress photos, extract EXIF

💾 STORES (State management)
- authStore: User login state, LogBooks list

🧭 NAVIGATION
- AppNavigator: Routes between screens

📋 ENTRY
- App.js: App startup and initialization

🗄️ BACKEND
- pocketbase-schema.json: Database structure


Development Workflow
=====================

1. Edit code in src/
2. Save file
3. App auto-reloads on phone (Fast Refresh)
4. Test changes immediately

No build step needed for development!


Production Build
=================

Later, when ready to distribute:

iOS:
  eas build --platform ios

Android:
  eas build --platform android

(Requires Expo EAS account - free tier available)
